## The Grove Ecosystem

The Grove is a multi-tenant blogging and community platform. Most of these projects now live inside **[Lattice](https://github.com/AutumnsGrove/Lattice)**, the monorepo that powers everything.

| Project | What it does | Status |
|---------|-------------|--------|
| **[Lattice](https://github.com/AutumnsGrove/Lattice)** | Core platform — UI engine, Glass design system, everything | Active, past v1.0 |
| **Heartwood** (GroveAuth) | Centralized OAuth 2.0 + PKCE authentication | In Lattice |
| **Amber** | Unified storage management (R2/D1) | In Lattice |
| **Foliage** | Visual theming system — 13 components, 10 WCAG themes | In Lattice |
| **Gossamer** | ASCII visual effects — clouds, image transforms, borders | In Lattice |
| **Shutter** | Web content distillation for LLM agents | In Lattice |
| **Ivy** | Zero-knowledge mail client for @grove.place | In Lattice |
| **Clearing** | Monitoring platform for Grove.place | In Lattice |
| **Vineyard** | Tool documentation and demos | In Lattice |
| **Patina** | Automated backup system across all Grove clients | In Lattice |
| **Vista** | Deployment monitoring for Grove sites | In Lattice |
| **Forage** | AI-powered domain discovery | In Lattice |
| **[Nook](https://github.com/AutumnsGrove/Nook)** | Private video sharing for close friends | Standalone (may join Lattice) |
| **[Solarium](https://github.com/AutumnsGrove/Solarium)** | The Celestial Observatory | Standalone |
| **[Shade](https://github.com/AutumnsGrove/GroveShade)** | AI crawler protection layer | Standalone |
| **[Mycelium](https://github.com/AutumnsGrove/Mycelium)** | MCP server for the Grove ecosystem | Standalone |
| **[Bloom](https://github.com/AutumnsGrove/GroveBloom)** | Serverless coding infrastructure | Standalone |
| **[Outpost](https://github.com/AutumnsGrove/GroveMC)** | On-demand Minecraft server for friends | Standalone |
| **[Scout](https://github.com/AutumnsGrove/GroveScout)** | Searching for deals, fast | Standalone |
| **[Aria](https://github.com/AutumnsGrove/GroveMusic)** | Music curation through sonic DNA matching | On hold |
